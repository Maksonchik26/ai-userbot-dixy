# 🚀 Быстрый старт

## 1. Установка

```bash
pip install -r requirements.txt
```

## 2. Настройка

1. Получите API ID и API Hash на https://my.telegram.org/apps
2. Создайте файл `.env`:
```
API_ID=ваш_api_id
API_HASH=ваш_api_hash
SESSION_NAME=userbot_session
```

## 3. Запуск

```bash
python userbot.py
```

При первом запуске введите номер телефона и код подтверждения.

## 4. Добавление в группу

### Для своей группы:
1. Откройте нужную группу в Telegram
2. Добавьте **свой аккаунт** в группу (тот же, что используется для userbot)
3. Userbot автоматически начнет собирать новые сообщения

### Для группы конкурентов (публичная группа):
1. Узнайте username группы (например, `@competitor_group`)
2. Напишите userbot в личные сообщения (Saved Messages)
3. Отправьте: `/parse @competitor_group`
4. **Готово!** Не нужно быть участником, если группа публичная

### Для приватной группы конкурентов:
1. Получите доступ к группе (попросите добавить или используйте ссылку)
2. Узнайте ID через @userinfobot
3. Отправьте: `/parse -1001234567890` (ID группы)

## 5. Команды

В личных сообщениях с userbot:
- `/parse @groupname` - парсинг истории
- `/parse @groupname limit=1000` - с ограничением
- `/stats` - статистика
- `/help` - справка

## 6. Экспорт данных

```bash
python export_data.py json    # Экспорт в JSON
python export_data.py csv      # Экспорт в CSV
python export_data.py stats    # Статистика
```

## ❓ Как узнать ID группы?

1. Добавьте бота @userinfobot в группу
2. Он покажет ID группы

Или используйте username группы, если он есть: `/parse @mygroup`

## ⚠️ Важно

- Userbot работает от **вашего имени**, не от имени бота
- Нужно добавить **себя** в группу, а не бота
- Для доступа к истории может потребоваться быть администратором
