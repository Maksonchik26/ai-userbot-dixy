# Telegram Userbot для парсинга сообщений

Userbot для сбора всех сообщений из Telegram групп для последующего анализа с помощью ИИ.

> 💡 **Почему userbot, а не обычный бот?** Обычные боты не могут читать историю сообщений и парсить данные. Userbot работает от вашего имени и имеет полный доступ к истории. [Подробнее →](USERBOT_VS_BOT.md)

## 🚀 Возможности

- ✅ Автоматический сбор новых сообщений из всех групп
- ✅ Парсинг истории сообщений по команде
- ✅ Сохранение в SQLite базу данных
- ✅ Сбор метаданных (автор, дата, медиа, ответы)
- ✅ Команды управления через личные сообщения
- ✅ Статистика по собранным данным

## 📋 Требования

- Python 3.8+
- Telegram аккаунт
- API ID и API Hash от Telegram

## 🔧 Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/aleksandrvolk/ai-userbot.git
   cd ai-userbot
   ```
   
   Или скачайте файлы вручную

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Получите API credentials:**
   - Перейдите на https://my.telegram.org/apps
   - Войдите в свой аккаунт
   - Создайте новое приложение
   - Скопируйте `api_id` и `api_hash`

4. **Настройте конфигурацию:**
   - Скопируйте `.env.example` в `.env`
   - Заполните `API_ID` и `API_HASH` в файле `.env`

```bash
cp .env.example .env
# Отредактируйте .env файл
```

## 🎯 Как добавить бота в группу

### Важно: Это userbot, а не обычный бот!

Userbot работает от имени **вашего личного аккаунта Telegram**. 

> 💡 **Для групп конкурентов (чужих групп):** См. подробную инструкцию в файле `ПАРСИНГ_ГРУПП_КОНКУРЕНТОВ.md`

Чтобы он мог собирать сообщения из группы:

### Способ 1: Добавление через интерфейс Telegram

1. **Добавьте свой аккаунт в группу:**
   - Откройте группу в Telegram
   - Нажмите на название группы → "Добавить участников"
   - Найдите и добавьте свой аккаунт (тот, который используется для userbot)

2. **Убедитесь, что у вас есть доступ:**
   - Бот должен видеть историю сообщений
   - Для приватных групп нужно быть участником
   - Для супергрупп может потребоваться быть администратором для доступа к истории

### Способ 2: Использование username группы (для публичных групп и групп конкурентов)

Если группа имеет публичный username (например, `@mygroup`), вы можете:
- Просто использовать команду `/parse @mygroup` в личных сообщениях userbot
- Userbot автоматически получит доступ, если группа публичная
- **Это работает даже для групп конкурентов, если они публичные!**

### Способ 3: Использование ID группы

1. **Узнайте ID группы:**
   - Добавьте в группу бота @userinfobot
   - Он покажет ID группы

2. **Используйте ID в команде:**
   ```
   /parse -1001234567890
   ```

## 🚀 Запуск

```bash
python userbot.py
```

При первом запуске:
1. Введите номер телефона (с кодом страны, например: +79991234567)
2. Введите код подтверждения из Telegram
3. Если включена двухфакторная аутентификация, введите пароль

После успешного входа сессия сохранится в файл `userbot_session.session` и повторный ввод не потребуется.

## 📱 Команды

Все команды работают только в **личных сообщениях** с userbot:

- `/parse @username` - Начать парсинг истории чата
- `/parse @username limit=1000` - Парсинг с ограничением количества сообщений
- `/stats` - Показать статистику по собранным сообщениям
- `/help` - Показать справку

### Примеры использования:

```
/parse @support_group
/parse @mycompany limit=5000
/stats
```

## 📊 База данных

Все сообщения сохраняются в SQLite базу данных (`messages.db` по умолчанию).

### Структура таблиц:

**messages:**
- `message_id` - ID сообщения в Telegram
- `chat_id` - ID чата
- `chat_title` - Название чата
- `chat_type` - Тип чата (group/channel/private)
- `user_id` - ID автора
- `username` - Username автора
- `first_name`, `last_name` - Имя автора
- `message_text` - Текст сообщения
- `date` - Дата сообщения
- `is_reply` - Является ли ответом
- `reply_to_message_id` - ID сообщения, на которое ответ
- `has_media` - Есть ли медиа
- `media_type` - Тип медиа
- `raw_data` - Дополнительные данные (JSON)

**chats:**
- `chat_id` - ID чата
- `chat_title` - Название чата
- `chat_type` - Тип чата
- `participants_count` - Количество участников
- `first_seen` - Когда впервые обнаружен
- `last_activity` - Последняя активность
- `metadata` - Метаданные (JSON)

## ⚠️ Важные замечания

1. **Userbot работает от вашего имени** - все действия выполняются от вашего аккаунта
2. **Соблюдайте лимиты Telegram** - при парсинге больших объемов могут быть задержки
3. **Права доступа** - для парсинга истории нужен доступ к группе
4. **Приватность** - убедитесь, что у вас есть право собирать данные из групп
5. **База данных** - регулярно делайте резервные копии `messages.db`

## 🔒 Безопасность

- Не публикуйте файл `.env` с вашими credentials
- Не публикуйте файл `*.session` - это ваша авторизация
- Добавьте `.env` и `*.session` в `.gitignore`

## 📝 Логирование

Логи сохраняются в файл `userbot.log` и выводятся в консоль.

Уровень логирования настраивается в `.env`:
- `DEBUG` - подробные логи
- `INFO` - информационные сообщения (по умолчанию)
- `WARNING` - только предупреждения и ошибки
- `ERROR` - только ошибки

## 🐛 Решение проблем

### Бот не видит сообщения в группе
- Убедитесь, что ваш аккаунт добавлен в группу
- Проверьте, что группа не является "супергруппой" с ограниченным доступом
- Попробуйте использовать команду `/parse` с username или ID группы

### Ошибка "ChatAdminRequiredError"
- Нужны права администратора для доступа к истории
- Или группа должна быть публичной

### Ошибка "FloodWait"
- Telegram ограничил запросы
- Бот автоматически подождет указанное время
- Уменьшите скорость парсинга (уже встроено)

### Сессия не сохраняется
- Проверьте права на запись в директорию
- Убедитесь, что есть место на диске

## 📤 Экспорт данных

Для экспорта данных используйте скрипт `export_data.py`:

```bash
# Экспорт всех сообщений в JSON
python export_data.py json

# Экспорт в CSV
python export_data.py csv

# Экспорт конкретного чата
python export_data.py chat -1001234567890

# Статистика по базе
python export_data.py stats
```

Экспортированные данные можно использовать для:
- Анализа с помощью ИИ
- Создания дашбордов
- Генерации отчетов
