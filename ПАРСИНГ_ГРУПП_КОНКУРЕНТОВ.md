# 🎯 Парсинг групп конкурентов (чужих групп)

## ⚠️ Важные моменты

1. **Userbot работает от вашего имени** - все действия видны как действия вашего аккаунта
2. **Нужен доступ к группе** - вы должны быть участником или группа должна быть публичной
3. **Соблюдайте правила Telegram** - не нарушайте условия использования

## 🔓 Варианты доступа к группе конкурентов

### Вариант 1: Публичная группа (самый простой) ✅

Если группа имеет **публичный username** (например, `@competitor_group`):

1. **Запустите userbot:**
   ```bash
   python userbot.py
   ```

2. **В личных сообщениях отправьте команду:**
   ```
   /parse @competitor_group
   ```

3. **Готово!** Userbot начнет парсить историю сообщений.

**Преимущества:**
- Не нужно быть участником группы
- Не нужно просить доступ
- Работает сразу

### Вариант 2: Приватная группа (нужен доступ)

Если группа **приватная** (нет публичного username):

#### Шаг 1: Получите доступ к группе

**Способ А: Попросите добавить ваш аккаунт**
- Попросите администратора группы добавить ваш аккаунт
- Или попросите друга, который есть в группе, добавить вас

**Способ Б: Присоединитесь сами (если есть ссылка-приглашение)**
- Если у вас есть ссылка-приглашение, присоединитесь через неё
- Откройте ссылку в Telegram и присоединитесь к группе

#### Шаг 2: Узнайте ID группы

После того, как вы в группе:

1. Добавьте бота @userinfobot в группу
2. Он покажет ID группы (например: `-1001234567890`)

Или используйте username, если группа стала публичной.

#### Шаг 3: Запустите парсинг

В личных сообщениях userbot:
```
/parse -1001234567890
```

или если есть username:
```
/parse @groupname
```

### Вариант 3: Канал (Channel)

Если это **канал** (не группа):

1. **Подпишитесь на канал** через Telegram
2. **Используйте username канала:**
   ```
   /parse @channel_name
   ```

Каналы обычно публичные, поэтому доступ проще.

## 📋 Пошаговая инструкция для группы конкурентов

### Сценарий 1: Группа с публичным username

```
1. Запустите: python userbot.py
2. В Saved Messages отправьте: /parse @competitor_group
3. Дождитесь завершения парсинга
4. Проверьте: /stats
```

### Сценарий 2: Приватная группа
Вручную
```
1. Получите доступ к группе (попросите добавить или используйте ссылку)
2. Узнайте ID группы через @userinfobot
3. Запустите: python userbot.py
4. В Saved Messages отправьте: /parse -1001234567890
5. Дождитесь завершения
``` 
или автоматизированно
```
Указать в .env в перечне каналов через запятую ссылку-приглашение на закрытый канал в таком формате:
https://t.me/joinchat/_Tcvkiu5MeFiN123
```

### Сценарий 3: Не знаете, публичная ли группа

```
1. Попробуйте найти группу в поиске Telegram по названию
2. Если находится - значит публичная, используйте username
3. Если не находится - приватная, нужен доступ
```

## 🔍 Как найти username группы?

1. **Откройте группу в Telegram**
2. **Нажмите на название группы** (вверху)
3. **Посмотрите в настройках** - если есть поле "Username" с `@...`, значит публичная
4. **Или посмотрите ссылку группы** - если есть `t.me/groupname`, используйте `@groupname`

## ⚠️ Ограничения и проблемы

### Проблема: "ChatAdminRequiredError"

**Причина:** Нет доступа к истории сообщений

**Решения:**
- Для публичных групп обычно работает через username
- Для приватных групп нужно быть участником
- Для супергрупп может потребоваться быть администратором для доступа к полной истории

### Проблема: "Username not found"

**Причина:** Неправильный username или группа приватная

**Решения:**
- Проверьте правильность username (без пробелов, с @)
- Убедитесь, что группа публичная
- Если приватная - получите доступ и используйте ID

### Проблема: Не могу получить доступ к группе

**Решения:**
- Попросите администратора добавить вас
- Используйте другой аккаунт (если есть)
- Если группа совсем закрытая - доступ может быть невозможен

## 💡 Рекомендации для групп конкурентов

1. **Используйте отдельный аккаунт** - создайте отдельный Telegram аккаунт для мониторинга конкурентов
2. **Не спамьте** - не отправляйте сообщения в группу конкурентов
3. **Ограничивайте парсинг** - используйте `limit=` для больших групп:
   ```
   /parse @competitor_group limit=1000
   ```
4. **Парсите регулярно** - настройте автоматический запуск для сбора новых сообщений
5. **Сохраняйте данные** - регулярно экспортируйте данные:
   ```bash
   python export_data.py json
   ```

## 🎯 Примеры команд

```bash
# Публичная группа по username
/parse @competitor_support

# Приватная группа по ID
/parse -1001234567890

# С ограничением количества
/parse @competitor_group limit=5000

# Канал
/parse @competitor_channel

# Проверка статистики
/stats
```
